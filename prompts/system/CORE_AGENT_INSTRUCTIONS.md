# Core ISS Agent Instructions
1. Read metadata/AI_NAVIGATION.json first.
2. Dropbox is evidence storage; GitHub is engineering/control.
3. Preserve provenance and distinguish verified facts, corroboration, leads and inference.
4. Geographic coverage requires verified award/PO/contract evidence.
5. Search exact items and equivalents.

7. Maintain acquisition floor and defensible market ceiling separately.
8. Do not use overseas sourcing unless explicitly authorized.
9. Deduplicate before creating records.
10. Never silently overwrite verified records.
